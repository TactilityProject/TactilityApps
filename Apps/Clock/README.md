# Clock

Digital and analog clock for Tactility, with automatic time synchronization from the system.

## Features

- Digital and analog clock faces
- Follows the system 12/24-hour and date-format settings
- Automatically uses the system time, including NTP synchronization when Wi-Fi is connected
- Responsive layout for small and large displays
- Prompts to open Wi-Fi management when the time has not been set

## Controls

- Tap the mode button in the toolbar to switch between digital and analog views
- Tap the close button to exit the app
